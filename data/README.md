# Data

Before publishing, copy the locally generated primary dataset into this folder as:

`ads_eligibility_locked.csv`

Expected row count: **53,794 Meta ad IDs** (plus the header row).

The primary observational unit is one Meta Ad Library ad ID per row. The dataset is not deduplicated by textual creative signature and demographic reach is not aggregated across Meta ad IDs.

The signature-enriched dataset produced by Script 08 is an audit/sensitivity resource rather than the primary analytical dataset.
